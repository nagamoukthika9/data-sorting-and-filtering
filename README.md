# Basic Data Sorting & Filtering

The objective was to practice basic data exploration using Microsoft Excel by sorting and filtering a Superstore sales dataset to answer business-related questions.

## Tools Used
- Microsoft Excel
- Superstore Dataset

## Tasks Performed
1. Preserved the original dataset.
2. Created a separate working sheet.
3. Sorted sales values from largest to smallest.
4. Filtered orders by customer segment.
5. Filtered products by category.
6. Filtered orders by date (2017).
7. Applied number filters to identify sales greater than $500.

## Business Questions Answered
1. Which order has the highest sales?
2. Which orders belong to the Consumer segment?
3. Which orders belong to the Technology category?
4. Which orders were placed in 2017?
5. Which orders have sales greater than $500?

## Key Findings
- Highest recorded sales: $22,638.48.
- Consumer segment filter returned 5,101 records out of 9,800.
- Technology orders were identified using category filtering.
- Orders from 2017 were isolated using date filters.
- Orders exceeding $500 were identified using number filters.

## Project Files
- Raw_Data: Original dataset.
- Working_Data: Dataset used for sorting and filtering.
- Answers: Business questions and findings.

## Learning Outcomes
- Understanding Excel sorting and filtering.
- Applying multiple filters.
- Exploring business datasets.
- Answering business questions using data.
